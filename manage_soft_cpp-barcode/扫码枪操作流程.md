# 库存软件扫码枪操作流程

## 1. 先说明：首次绑定和扫码入库是否重复？

不属于同一件事：

- **首次绑定**：告诉系统“这个条码对应哪一种物料”，只建立物料与条码的关系。
- **扫码入库**：记录“这一次实际增加了多少库存”，并生成入库历史。

不过，新物料第一次到货时，可以使用“新增入库项目”一次完成建档、绑定条码和入库，不需要再执行一次扫码入库。

### 推荐判断方式

```text
收到物料
  ├─ 系统里没有这种物料
  │    └─ 入库 → 手动 → 新增入库项目
  │       一次完成：建档 + 扫条码 + 填数量 + 入库
  │
  ├─ 系统里有物料，但还没有绑定条码
  │    └─ 先编辑物料绑定条码 → 再执行扫码入库
  │       绑定只做第一次，以后不再重复
  │
  └─ 系统里已有物料，而且已经绑定条码
       └─ 直接点击“扫码入库”
```

## 2. 扫码枪准备

本软件使用扫码枪的键盘/HID模式，不需要安装扫码枪SDK。

### 连接方式

- USB有线扫码枪：直接插入电脑USB接口。
- 无线扫码枪：将USB接收器插入电脑，然后打开扫码枪。

### 必要设置

扫码枪应设置为：

1. 键盘/HID模式。
2. 扫描完成后自动发送 Enter（回车）。
3. 电脑建议切换到英文输入法。

### 使用记事本测试

1. 打开Windows记事本。
2. 将光标点进记事本。
3. 扫描任意条码。
4. 应出现完整条码，例如 `6901234567890`。
5. 扫描完成后光标应自动换到下一行。

如果条码能出现但不会自动换行，需要按照扫码枪说明书扫描“添加Enter后缀”配置码。

## 3. 场景一：新物料第一次到货

这是最推荐的首次使用流程，可以一次完成物料建档、绑定条码和入库。

### 操作步骤

1. 打开软件并进入“库存管理”。
2. 点击“入库”。
3. 选择“手动”。
4. 在“手动入库详情”窗口中点击“新增入库项目”。
5. 填写物料资料：
   - Manufacturer Part（厂家料号，必填）
   - Quantity（本次入库数量，必填）
   - 存储位置
   - 日期
   - 名称、厂家、单位等其他资料
6. 将光标点进“条码”输入框。
7. 扫描物料包装上的条码。
8. 检查条码和入库数量。
9. 确认新增入库项目。
10. 返回入库明细后，确认并提交本次入库。

### 结果

系统会同时完成：

- 创建物料档案；
- 将条码绑定到该物料；
- 增加本次入库数量；
- 生成入库历史记录。

完成后不要再点击“扫码入库”，否则会把同一批物料重复入库。

## 4. 场景二：已有物料第一次绑定条码

适用于系统里已经有物料和库存，但以前没有使用条码的情况。

### 操作步骤

1. 进入“库存管理”。
2. 搜索并找到对应物料。
3. 选中物料并点击“编辑”。
4. 找到“条码”字段。
5. 将光标点进条码输入框。
6. 扫描物料包装上的条码。
7. 确认物料信息和条码正确。
8. 保存。

这一步只建立条码关系，不应修改库存数量。

如果绑定条码的同时确实收到了一批新货，保存后再按照下一节执行一次扫码入库。

## 5. 场景三：已绑定条码的日常扫码入库

### 操作步骤

1. 进入“库存管理”。
2. 点击“扫码入库”。
3. 扫描物料条码。
4. 扫码枪输入条码并自动发送回车。
5. 软件自动查找物料并显示：
   - 物料信息；
   - 当前库存；
   - 单位和存储位置等资料。
6. 输入本次实际入库数量。
7. 检查业务日期。
8. 根据需要填写备注，例如采购单号、供应商或批次信息。
9. 点击“确认”。

### 示例

```text
当前库存：120
本次入库：500
入库后库存：620
```

系统会生成历史记录，录入方式显示为“扫码枪”。

## 6. 日常扫码出库

### 操作步骤

1. 进入“库存管理”。
2. 点击“扫码出库”。
3. 扫描物料条码。
4. 软件自动查找对应物料。
5. 核对物料名称和当前库存。
6. 输入本次出库数量。
7. 检查业务日期。
8. 填写领用人、项目名称或用途等备注。
9. 点击“确认”。

### 示例

```text
当前库存：620
本次出库：50
出库后库存：570
```

如果出库数量大于当前库存，软件会拒绝操作，库存不会变成负数。

## 7. 扫码后提示“未找到物料”

可能原因：

- 物料尚未绑定条码；
- 扫描的是物流单号或订单号；
- 包装上存在多个条码，扫描了错误的条码；
- 这是第一次到货的新物料。

处理方法：

- 新物料：使用“入库 → 手动 → 新增入库项目”。
- 已有物料：编辑物料，先绑定正确条码，然后重新扫码。

当前版本不会在“扫码入库”找不到条码时自动创建物料，目的是避免把物流码、订单码误建成库存物料。

## 8. 扫码后提示“条码重复”

系统要求一个条码只能绑定一种物料。

出现重复提示时：

1. 使用条码在库存搜索框中搜索。
2. 检查重复绑定的物料。
3. 保留正确物料的条码。
4. 删除或修改错误物料上的条码。

## 9. 包装上有多个条码时如何选择

电子元器件包装上可能同时有：

- 厂家料号条码；
- 供应商商品编号；
- 批次号；
- 订单号；
- 快递物流码；
- 二维码。

优先选择能够长期、稳定、唯一代表该物料型号的条码。不要选择每次采购都会变化的订单号、快递单号或包装流水号。

## 10. 仓库推荐工作流程

```text
新物料首次到货
  ↓
新增入库项目
  ↓
填写物料资料并扫描条码
  ↓
填写首次入库数量并提交
  ↓
以后到货直接扫码入库
  ↓
领料时直接扫码出库
  ↓
通过库存历史核对操作人员、时间和数量
```

## 11. 重要注意事项

1. 新物料使用“新增入库项目”后，不要对同一批货再执行扫码入库。
2. 已有物料首次绑定条码时，不要顺手修改库存数量。
3. 每次入库和出库都填写实际变更数量，不是填写变更后的总库存。
4. 扫描前确认输入光标位于扫码窗口或条码字段中。
5. 同一种物料建议统一使用一个稳定条码。
6. 操作完成后可以在库存历史中检查记录，扫码操作的录入方式为“扫码枪”。
